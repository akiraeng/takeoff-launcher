# Security Policy

## Supported Versions

Security updates and patches are provided for the latest released version:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Takeoff runs locally on your Windows desktop and does not process untrusted remote inputs, run network listener servers, or execute untrusted code. However, if you discover a security vulnerability (such as a local privilege escalation or unsafe shortcut execution flaw), please report it responsibly.

Please do **NOT** open a public issue. Instead, report vulnerabilities by emailing:

**akiraredddd@gmail.com**

Include the following details in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the behavior.
- Affected Windows version and Takeoff build.

You will receive an acknowledgment within 48 hours. If the issue is confirmed, a security patch will be prepared and released promptly.
